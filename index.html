The six-check gap is not retrieval. Every system scored 72/72 on retrieval. It comes entirely from a synthetic composite code-reasoning check: 7/18 for RiNGSiDE and 13/18 for each EXL3 variant. A follow-up A/A showed enough item-level variance that this must remain a signal, not a causal quantization claim.

What held up

Long-context retrieval

Perfect across all six sizes, including ~260K real prompt tokens, for all three serving systems.

Bounded agentic tasks

RiNGSiDE led the common track at 16/24 verified successes, versus 13/24 and 12/24.

Ordinary tool selection

Domain selection, conditional planning, accumulated constraints, and simple schema compliance were stable.

What stayed fragile

Composite code reasoning at depth

RiNGSiDE showed a repeatable local weakness even though it retrieved the required facts.

Adversarial tool constraints

All variants failed missing-required-argument and strict schema-resistance tests.

Long horizon

Every system ended partial on all six runs. This protocol did not separate the recipes.

Interpretation without overclaiming

RiNGSiDE preserved retrieval and performed strongly on the bounded agentic track. The negative signal is specific: mental execution or composition of distant code facts. That is worth documenting, but it does not support a blanket statement that NVFP4 degrades GLM-5.3 Flash quality.

The systems also differ in node count, tensor parallelism, serving runtime, speculative drafter, parser behavior, and context configuration. These are complete-system results—not a pure NVFP4-versus-EXL3 experiment.

Scope note: the tested Mia system is the pinned EXL3 vLLM recipe, not the newer TensorFold recipe.
